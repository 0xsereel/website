# REPO CONTEXT
This file contains important context about this repo for [Tonkotsu](https://www.tonkotsu.ai) and helps it work faster and generate better code.

## Technology Stack
- React + TypeScript + Vite
- Tailwind CSS
- ESLint for linting
- Package manager: npm or pnpm (both lock files present)

## Setup Commands

### Initial Setup
```bash
# Install dependencies (use npm or pnpm - both lock files are present)
npm install
# OR
pnpm install
```

### Build
```bash
npm run build
# OR
pnpm build
```

### Lint
```bash
npm run lint
# OR
pnpm lint
```

### Tests
No test framework is currently configured in this project.

### Dev Server
```bash
npm run dev
# OR
pnpm dev
```

### Preview Production Build
```bash
npm run preview
# OR
pnpm preview
```

## Notes
- This is a Vite-based React application with TypeScript
- Uses Tailwind CSS for styling via @tailwindcss/vite plugin
- ESLint is configured for code linting
- No testing framework is currently set up
- Both npm and pnpm lock files exist - either package manager can be used
